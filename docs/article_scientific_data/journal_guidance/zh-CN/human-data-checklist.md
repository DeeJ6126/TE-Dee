# 人类来源数据投稿检查表（中文阅读译本）

原件：[官方 Word 表格](../official_files/sdata-sensitive-data-checklist.docx)；[官方下载地址](https://www.nature.com/documents/sdata-sensitive-data-checklist.docx)。获取日期：2026-09-02。

这是未填写表格的中文阅读译本，**不替代正式英文表格，不代表已作出任何伦理声明或签名**。翻译保留各问题、分支跳转及附后指导；Word 中重复的输入框提示合并一次，排版控件省略。英文表格及最新政策优先。

## 使用说明

所有描述人类来源数据的 Scientific Data 作者都须提交本表，例如生物研究、医疗数据、个人信息、问卷回答等。表格在首次评审决定阶段检查，内部编辑团队不在送审前预先完成合规评估。

请确保共享方式符合政策，先阅读末尾指导。不确定时联系 `scientificdata@nature.com`。不合规可能延误发表或导致拒稿。

请阅读指导、回答问题、确认相关信息也写在主文中、签署表格，并作为 **Related Manuscript file** 上传。一位作者签名即可，可采用电子签名。

## 问题 1：如何取得参与者同意？

数据若来自多个渠道，应选择所有适用选项并回答对应后续问题。

- [ ] 已直接从参与者取得参与研究及数据共享的知情同意，可在采集时或针对未来使用取得，并已在 Methods 中说明。
- [ ] 在上一种情形下，参与者不能合理自主同意，由父母、监护人或其他适当责任人同意，且已在 Methods 中说明。继续问题 2。
- [ ] 患者未被告知或未同意共享，例如常规医疗或非医疗情形，但第三方已同意豁免，并已在 Methods 中解释。仅适用于充分匿名且不涉及脆弱群体的数据。继续问题 2。
- [ ] 未直接接触或收集活体患者数据，而是分析生物样本库、商业供应商或其他来源的已有样本材料。Methods 应详细说明来源，使他人能找到并取得，并确认遵守供应方条款。**跳至问题 7，跳过其他问题。**
- [ ] 未接触活体患者，而是从外部仓储下载已有的人类数据，构建二次数据集。同意管理由原数据所有者负责；使用者应检查复用条款并遵守，在 Methods 中说明准确来源及已核实使用符合条款。**跳至问题 7，跳过其他问题。**
- [ ] 数据来自其他公共来源或公开文件，例如新闻，且不分享新的个人数据。**跳至问题 7，跳过其他问题。** 社交媒体不属于此例外；如共享 X、Facebook、Reddit、微信、Telegram、分类广告等数据，投稿前联系期刊。

## 问题 2：取得了哪些伦理批准？

- [ ] 作者机构的伦理委员会或 IRB 已批准数据采集和研究；该机构应与至少一名作者的单位相符。作者机构没有委员会时，可由第三方或独立 IRB 批准。填写下列信息，继续问题 3。

待作者填写：委员会名称、申请编号，并确认两者写入 Methods。若问题 1 选择同意豁免，也应在表格和主文说明该委员会是否提供了豁免。

## 问题 3：采用哪种共享方式？

定义和风险标准见附后指导。

- [ ] **开放共享：** 使用 CC0 或 CC BY 等开放许可，无下载障碍，审稿人可匿名访问。用于非敏感、无或低识别风险的数据；少数情况下，也可用于已取得充分知情同意的可识别数据。仓储和链接应写入 Data Records。**跳至问题 7。**
- [ ] **受控访问：** 存在重新识别患者或参与者的风险，可能伴随高度敏感字段；某些使用具有识别、个人信息披露或 GDPR 等具体风险，需要控制。所有用户须签署列明限制的 DUA。文中应说明访问方式和限制理由。继续问题 4。

开放共享选项的原文字面说明“不接受 NC，需用时投稿前联系”；附后指导另明确允许二次数据继承输入数据的 NC 条款。两处须合并理解，不要省略例外或自行扩大许可。

非敏感、没有识别风险但缺少同意的数据，通常不应仅因此改成受控访问；应向 IRB 请求风险评估及同意豁免。

## 问题 4：数据包含哪些内容？

选择所有适用项目，列出具体字段，继续问题 5。

- [ ] **直接标识符：** 姓名、可识别面部图像、生物识别信息、基因组或转录组数据，意味着直接识别或披露风险。待填写：字段名称。
- [ ] **三个或更多间接标识符：** 例如位置、性别、宗教、族群或其他人口学字段；组合后可能把样本人群缩小到可识别范围。待填写：字段名称。
- [ ] **敏感或受保护字段：** 种族或民族、政治观点、信仰、工会身份、健康或诊断、心理评估、财务、犯罪记录等。它们不直接识别个人，但去匿名后可能造成披露风险。待填写：字段名称。

若数据不能识别个人，可能更适合开放共享，参见问题 3。

## 问题 5：编辑和未来读者能否取得 DUA？

请说明协议位置。条款在首次评审决定时检查。回答后继续问题 6。

DUA 应公开，通常在数据页面或仓储中提供。尚未公开时，作为 Related Manuscript file 随稿上传副本，并说明已经提供；已公开时给出可供编辑下载的 URL。

## 问题 6：有哪些实际访问控制，审稿人如何取得数据？

说明评审阶段访问方式，以及数据公开、论文发表后的访问流程。随后继续问题 7。

- [ ] **无注册、认证或人工审批等实际控制。** 仍需让用户阅读并确认遵守 DUA。若仓储界面直观，易于查看条款和下载，不必在正文专门说明操作。
- [ ] **自动注册、验证及接受 DUA，无人工筛选。** 提供有效邮箱、姓名、同意条款后立即获得链接或凭证。应在 Usage Notes 说明。审稿人必须确认注册不会向作者暴露身份，且同意条款后立即取得数据。制作临时 PDF，作为 Article 文件附在稿件前，告知审稿人可使用常规流程。
- [ ] **通过仓储人工申请或注册，超出基本邮箱核验。** 应在 Usage Notes 说明。必须有不会泄露审稿人身份、不会拖延审查的特别访问路线，或直接下载的数据样本。将私有链接、登录方式、样本 URL 等说明制作临时 PDF，作为 Article 文件附于稿件前；应基本即时可用。

无法满足时，正式投稿前联系 `scientificdata@nature.com`。

## 附后指导

### 两种共享方式

**A：完全开放。** 数据充分匿名、重新识别风险极低，或者无敏感字段；不需要使用限制；可直接 HTTPS 下载或即时注册后取得；采用 CC BY、CC0 或等效许可。对于输入数据本来带 NC 条款的二次数据集，可接受继承非商业限制，其他理由很少获准。

**B：受控访问。** 数据未充分匿名，或者敏感信息披露有风险；所有用户注册，记录姓名及单位；所有用户签署 DUA 或其他规定使用限制的合同。

两者主要针对首次公开的新数据。公共数据库已有数据形成的二次数据通常不适用同样的人类数据共享政策，但必须遵守原所有者条款，尤其确认再分发权。期刊一般不要求二次利用另获伦理审批，但数据方、平台或机构可能要求。

### 对 A/B 都检查的事项

- 已有知情同意，或者 IRB 同意豁免。豁免仅适用于采集时无法取得同意、完全匿名、非生物识别数据，不用于儿童或脆弱成年人。
- IRB 或伦理委员会批准研究，并批准数据共享。

### B：为什么需要限制？

遵循“尽可能开放，必要时才限制”。默认开放，存在具体风险才限制。风险通常来自个人或非匿名信息。数据所有者应判断文件类型、直接标识符与多个间接标识符造成的风险，并采取相称控制。

基因组、姓名、面孔为直接标识的例子；位置、性别、医疗特征、职业等可共同缩小人群。既能识别个人又有政治、宗教、财务、健康、性身份等敏感字段时风险最高。

### B：主要以法律承诺管理风险

用户须签署 DUA 并承诺遵守。通常仅需注册、身份核验和主动同意条款，而不是提交研究计划并由委员会逐项判断。

一般应允许所有身份可核验且接受条款的用户使用，不按研究问题、国家、机构或机构类型（学术、政府、商业）等与保护无关的条件筛选。

少数确需人工判断时，应说明问题、判断内容及其如何实际降低风险。

### DUA 通常应有的条款

- 禁止直接或通过跨来源关联重新识别参与者。
- 禁止向协议未列名或未签署的人再分发；所有用户直接获取并签约。
- 仅内部研究或分析，产出、衍生物不得泄露原始数据，不与参与者外部联系。
- 安全管理数据，具备控制和培训。

可以加入有限责任、泄露应对、说明 DUA 不增减既有知识产权保护、要求正式引用，以及 CC BY 等标准许可包含的条款。

原文给出的可接受协议示例为 PhysioNet Credentialed Health Data Use Agreement 1.5.0；其链接为 [PhysioNet 协议页面](https://physionet.org/content/mimiciii/view-dua/1.4/)。名称和 URL 中版本数字不同，按原件保留，未替其修订。

### DUA 常见不允许的条款

协议应保护人类健康数据，期刊可能要求删除与保护目的无关的限制。下列并非穷尽；有疑问在投稿前联系期刊。

- 付费才能取得数据。
- 对不泄露原数据的算法、结果等衍生物主张知识产权或另加限制。
- 要求作者发表前把相关论文交给数据方。
- 要求数据方和二次使用者共同署名。
- 仅学术或非商业使用。通常应约束使用方式，而非用户身份；定义清楚且允许安全、合法商业研发的“仅研究”或“仅内部研究”可能接受。
- 超出参考文献中引用数据集或论文之外的额外归属要求。
- 超出现有法律规定的明确罚款。
- 过多研究计划披露或人工申请要求。期刊认为保护主要来自法律承诺，而不是凭研究计划或个人资料预测合规风险。若采用委员会、人工审核或“申请后提供”方式，必须说明具体检查什么、为什么以及如何降低风险；投稿前提供允许和拒绝的标准或例子，联系期刊确认。
