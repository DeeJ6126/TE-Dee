# 投稿资料包说明（中文译文）

对应文件：[英文 README](../README.md)。资料采集日期：2026-09-02。

目标期刊是 **Scientific Data，不是 Scientific Reports**。这是参考资料集合，不是论文或已准备好的投稿包。

## 从哪里开始

先阅读[要求速查](requirements.md)，再核对[完整投稿指南正文译文](submission-guidelines.md)中的文体表、初投及返修章节。查看[人类数据表译文](human-data-checklist.md)，实际填写仍使用未改动的[英文官方表格](../official_files/sdata-sensitive-data-checklist.docx)。正式投稿前重新检查官网。

## 模板检索结论

当前指南不鼓励论文模板，并明确提醒不要使用旧版 LaTeX/Overleaf 模板。因此没有下载旧稿件模板，也没有自行创建“官方模板”。依据见[官方指南](https://www.nature.com/sdata/submission-guidelines)中的 General 和 LaTeX 章节。

## 来源与限制

- [来源登记](../sources.json)记录九份下载的官方 URL。
- [下载记录](../download_manifest.json)保存获取时间、HTTP 状态、大小、内容类型、SHA-256。
- 英文 HTML 保留下载时的原始响应，包含导航和脚本；没有打包样式、图片等依赖，不是完整离线镜像。导航和投稿应使用官网。
- 原文件版权不变，为参考而下载不代表可把出版方材料随 TE-KG 数据一起再发布。
- requirements.md 是 AI 整理的说明，不是官方文件或论文内容；完整官方原文优先。
- 没有登录期刊账号、启动投稿、填写或签署任何表格。

## 写作边界

上一轮确定由你亲自写论文，不自动起草或改写正文、摘要、附信、回复和声明；支持范围为你要求的资料收集、事实核查、材料整理和技术格式检查。

本轮进一步明确：只翻译投稿资料，不翻译既有项目研究材料，也不生成项目初稿。今后你若明确要求某项内容帮助，再按当时的具体请求处理。个人选择与期刊是否允许某种 AI 使用，不能混为一谈。
