Scientific Data 的文章发表后立即在网上永久免费提供，不收订阅费，也不要求读者注册。作者保留文章版权，并按适用许可，预先且持续地授权第三方使用、复制或传播文章。开放获取有助于扩大传播范围和读者群；相关介绍见英文页链接。

## 资助与减免

Springer Nature 提供开放获取资助支持信息，介绍可支付 APC 的资助方及机构。部分机构协议可以覆盖费用；作者应核对自身是否符合资格、Scientific Data 是否包含在协议内。

对于通讯作者位于全球最低收入国家的全开放获取期刊文章，出版方提供相应减免或折扣，具体以政策为准。

其他作者的申请按个案评估，经济困难时可能获得减免。**酌情减免或折扣必须在初次投稿时申请，审稿期间或接收后提出的不予考虑。**

## Creative Commons 许可

开放获取文章采用 Creative Commons 许可，作者仍保有版权。该页列出 Scientific Data 的两种文章许可：

- **CC BY-NC-ND 4.0：** 署名、非商业、禁止演绎。注明作者后可非商业分享原文；商业复用或分享修改、衍生版本须另获许可。
- **CC BY 4.0：** 署名。注明作者后可为任何目的分享、改编，包括商业用途。

若作者依法不能保留版权，例如某些美国政府雇员，应在投稿前联系开放研究支持团队，确认特殊版权安排是否可以接受。选择开放获取许可前，应核对资助方要求。
