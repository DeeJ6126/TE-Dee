# 办刊宗旨与范围（中文译文）

原文：[官网](https://www.nature.com/sdata/aims-and-scope)；[本地英文快照](../official_pages/aims-and-scope.html)。快照日期：2026-09-02。非官方正文译文，以英文为准。

Scientific Data 是专注数据的开放获取期刊，发表研究数据集的描述，以及研究数据共享相关文章，覆盖自然科学、医学、工程和社会科学。

期刊认为：开放共享研究数据对科学进步至关重要；介绍如何获取和使用数据的文章，能促进发现与复用，实现跨学科的 FAIR 目标；科学有效且可能对他人有用的数据应得到描述和共享。文章须有原创贡献，但不按预期重要性或影响力评判。

## 文章类型

**Data Descriptor：** 描述新的开放研究数据集，促进复用，不报告数据是否支持某个假说或结论。内容包括数据如何产生（Methods）、包含什么（Data Records）、如何检查和验证（Technical Validation），并提供生成数据使用的代码。

**Article：** 讨论数据政策、仓储、标准、本体、工作流，或公共仓储内数据共享的运行机制。期刊不发表利用数据验证一般科学假说的传统研究论文。也接受有关数据政策、工作流或基础设施的短评、观点，可以更具探索性，不必报告特定技术或发现；过去的 Comment 现并入 Article。

符合范围、政策和指南的稿件会送同行评审。介绍仓储的 Article 应先核对[仓储政策](repositories.md)中支持的平台类型；标准、流程、政策和整理等工作也应与这类平台相关。

## 接收标准

Data Descriptor 的采集和处理方法必须正确且适合所述数据；数据的标准、格式、原始程度及仓储应符合领域惯例，并公开共享。只要预期至少对另一个研究团队有用，就不按其影响力评判，不限制学科或数据类型。

文章可以与此前的结果论文相关，但所共享数据的多数不应已经通过另一篇论文的数据可用性声明公开。Article 应就研究数据主题提出新的发现或观点，技术上可靠，但不以结果影响力作为判断依据。

符合技术要求的稿件交由外部审稿人评估技术可靠性。原文说明，技术可靠的论文会被接收；这应结合完整范围、数据与政策要求理解，不是对具体稿件的接收保证。

Data Descriptor 将传统叙述与结构化数据描述结合，为共享数据提供框架。相关原则与 FAIR 一致：Findable（可发现）、Accessible（可访问）、Interoperable（可互操作）、Reusable（可复用）。

## 基本原则

### 贡献认可

符合 FAIR 的数据共享应获得恰当认可。期刊为数据创建提供可引用、经过同行评审的学术成果，也认可可能不符合传统研究论文作者资格的数据贡献者，并为不适合传统研究期刊的有价值数据提供发表途径。

### 复用

标准化、详细的数据说明有利于发现和复用。Data Descriptor 提供解释、复用、复现数据所需的信息，关联保存文件、代码或工作流的仓储，并通过展示复用潜力满足资助方数据管理要求的重要部分。

### 质量

真正可复用的数据需要严格评估其研究过程与描述完整性。同行评审聚焦论文和数据的技术质量及完整性；多领域专家组成的编委会维护标准，编辑和审稿人检查是否符合领域规范。

### 发现

研究者应能轻松找到相关数据。期刊内容可以统一检索，并提供经验证的仓储记录链接，帮助发现不同数据类型，促进整合分析。

### 开放

期刊希望研究者能够便利地联系合作，因此致力于方法、观察和采集过程透明；使用允许修改和衍生的开放许可；减少跨学科障碍；让科学家、政策制定者、非政府组织、企业、资助方及公众都能找到、访问、理解和复用所需数据。
