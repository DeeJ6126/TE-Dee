# 数据仓储指南（中文译文）

原文：[官网](https://www.nature.com/sdata/policies/repositories)；[本地英文快照](../official_pages/repositories.html)。快照日期：2026-09-02。非官方正文译文，以英文为准。

Scientific Data 要求把数据提交到适当的公共数据仓储。有领域专门且获社区认可的仓储时应优先使用，否则使用综合仓储。

第二轮同行评审起必须完成正式存储，以便检查合规并准备发表。第一轮也建议这样做，但允许作者暂用非正式共享，例如私有云链接，前提是下载顺畅且审稿人匿名。

## 所有数据仓储的通用要求

- 长期保存数据及其已发表的版本。Data Descriptor 必须持续关联可取得的数据，以免损害论文的完整性。
- 允许同行评审访问。需要登录或其他限制时，必须提供不向作者或数据方暴露审稿人身份的访问路线；与仓储协商，或提供临时副本。
- 提供稳定持久标识符；大多数非组学数据默认使用 DOI。
- 从 DOI 登记页面可以直接通过 HTTPS 下载，最好能作为一个整体取得。

## 非敏感（原文标题括注：非人类）数据

允许公众访问，不应设置正式申请等障碍。仅用于使用统计的基本注册或登录可接受，但须在邮箱确认后立即访问，不得人工审核。多数情况下仍鼓励免注册、免登录的 HTTPS 下载。

通常要求 CC0、CC BY 或等效开放许可，以尽量支持复用。一般不允许 SA（相同方式共享）或 NC（非商业）限制；但二次数据需要继承第三方原数据的同类许可条款时可例外。

输入数据若有 ND（禁止衍生）条款，不能据此获得上述例外，因为 ND 通常禁止编制二次数据集等衍生行为。

特别大型数据集可能豁免部分要求，原文阈值写作 `>1 Tb`，原因是该规模下满足全部要求可能较困难。

## 敏感人类数据的受控仓储

- 通过注册或登录核验用户身份。
- 支持 DUA，以规定允许和不允许的使用方式并管理风险。
- 只有已注册、通过验证且签署 DUA 的用户能够下载。

完整说明见[人类数据政策](data-policies.md)。

## 如何寻找仓储

某些数据类型必须使用特定仓储，包括基因组、转录组、蛋白质结构、蛋白质组、小分子晶体学等；完整名单请通过英文页中的 Springer Nature mandated data types 链接查看。

其他数据类型，Scientific Data 不指定、不背书、也不推荐某一家服务，作者可以选择任何符合以上政策的仓储。

可参考原页面链接中的 Springer Nature 历史推荐仓储名单、DataCite Repository Finder、FAIRsharing 和 re3data。历史名单已不再强制执行，也不再更新，仅为寻找候选仓储提供参考。
