# Preparation Scope

## Working Orientation

The target journal is Scientific Data. Data Descriptor is the provisional
preparation lens, not an author-approved article-type decision. The reusable
object is a versioned human TE evidence dataset with provenance and technical
validation; the website is one access route, not a substitute for data records.

Official guidance distinguishes Data Descriptor from Article, and emphasizes
dataset descriptions, methods, data records, technical validation, and reuse.
This workspace organizes evidence accordingly without imposing typography,
reference style, authoring software, or a manuscript section template.
[Scientific Data submission guidance](https://www.nature.com/sdata/publish/submission-guidelines)
(accessed 2026-09-02).

## Dataset Layers to Prepare

- Literature-derived entity and relationship records with PMID provenance.
- TE identity/classification crosswalks and source-specific genomic annotations.
- Consensus/reference sequences, subject to redistribution permissions.
- Expression matrices, sample metadata, and derived context summaries.
- Full co-expression networks and their separately identified display subsets.
- GTEx v11-derived TE-instance/Variant overlaps, Variant-Gene-Tissue
  associations, TE-Gene summaries, and identity-mapping audit records.

The eQTL input contains 50 named GTEx tissue categories, including cultured-cell
categories. Do not turn this into 50 homogeneous tissue experiments or combine
their sample counts with the three reused co-expression contexts.

## Exclusions

No manuscript prose drafting, claims of biological discovery, new analyses,
new benchmark, figure generation, data reimport, or website modification.
No transfer of OUP templates, CSL/BST files, old submission statements, page
counts, formatting QA, fixed four-figure layout, or Database-specific commitments.
Papers published in Database are not automatically excluded as scientific
references; only their use as mandatory journal-writing models is dropped.

## Availability Boundary

A local MySQL import and a working Download page are not an archival release.
Confirm a suitable repository, reviewer access, version identity, permissions,
and reproducible files before stating availability.
[Scientific Data data policies](https://www.nature.com/sdata/policies/data-policies)
(accessed 2026-09-02).

No decision about the final title, authors, licence, repository, or release
scope is made on behalf of the authors.
