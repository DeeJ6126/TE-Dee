inventory; it is not a finished figure plan or mandatory journal layout.

## Candidate Materials to Assemble Later

- Source-to-record diagram: add GTEx significant pairs/eGenes -> REF-span
  overlap -> normalized association tables. Keep graph PMID provenance separate.
- Schema/data dictionary: TE instance -> Variant -> Gene/tissue; explicit
  unique keys, coordinates, version and source identities.
- Compact dataset overview: historical versus released counts, separate
  dimensions/facts/summaries. Existing CSVs are sources, not completed figures.
- Validation material: boundary fixtures, per-tissue reconciliation, identifier
  mapping outcomes, missing-name coverage and reproducibility checks.
- Reuse example: reconstruct a strict overlap and tissue association from records,
  then optionally show its co-expression counterpart. Include one different TE
  class/name and a missing-evidence case if claiming wider utility.

For the provisional Data Descriptor orientation, keep summaries concise and
put the work into data definitions and validation rather than a Results/
Discussion narrative. No fixed figure count is imposed here.
[Scientific Data guidance](https://www.nature.com/sdata/publish/submission-guidelines)
(accessed 2026-09-02).
